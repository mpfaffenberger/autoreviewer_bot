Create the autoreviewer GitHub App

This registers a private App on your personal account (only you can install it; it can be made public later). Permissions: Pull requests, Checks write; Contents, Issues, Metadata read. You can still change the name on GitHub's page before creating it.

Next: GitHub sends you to review.chaos-emerald.com/github/app-created?code=…, which won't load yet. Copy the code from the address bar and hand it over (or run deploy/github-app/convert.sh CODE). It expires after one hour.
